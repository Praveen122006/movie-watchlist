# Movie Watchlist

## Project Description
A simple ReactJS movie watchlist application for managing movies, ratings, genres and viewing status. Movie data is stored in the browser using localStorage.

## Problem Statement
Problem 59 – Movie Watchlist Application

**Requirement:** Add movies, assign ratings, categorize them, and track viewing status.

## Features
- Add movies
- Edit movies
- Delete movies
- Search movies
- Filter movies
- Movie posters
- IMDb rating
- Personal rating
- Genre categorization
- Watched/Not Watched status
- Dashboard statistics
- Form validation
- LocalStorage
- Movie details modal

## Technologies Used
- ReactJS
- JavaScript ES6
- HTML5
- CSS3
- React Router DOM
- LocalStorage
- Vite

## How to Run
```bash
npm install
npm run dev
```
Then open the localhost URL shown by Vite.

## Project Structure
- `src/components/` – reusable UI components such as Navbar, MovieCard, filters and movie details.
- `src/pages/` – Dashboard, Watchlist and Add/Edit Movie pages.
- `src/data/` – sample movie data.
- `src/App.jsx` – main state, routing and localStorage logic.
- `src/App.css` – application styling and responsive design.

## Poster Images

The sample movies use poster images stored locally in `public/posters/`. This keeps the sample posters available without a movie API or API key. New movies can still use an optional poster URL from the Add Movie form.
